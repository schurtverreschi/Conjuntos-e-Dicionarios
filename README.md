# Praticando Python
Arquivo utilizado para organizar as atividades praticas do curso de pratica da Alura
## Objetivo:
Revisar e reforçar os conhecimentos aprendidos de conjuntos e dicionários
## Atividades:
- lista_convidados: Utiliza um conjunto para armazenar os nomes dos convidados e garantir que não será possível repetir convidados;
- palavra_em_comum: Faz a comparação entre dois textos e coloca as palavras em comum num conjunto;
- comparando_lista_compras: Faz a comparação de duas listas de compras e informa o que tem em comum em ambas e o que é exclusivo de cada;
- permissões: Verifica se todas as permissões solicitadas estão dentro do conjunto de permissões principais;
- lista_ tarefas: Combina dois conjuntos de tarefas e depois remove um elemento informado pelo usuário;
- dicionário_estoque: Adiciona uma quantidade pré determinada de itens a um dicionário;
- atualizando_estoque: Atualiza a quantidade de itens de um determinado elemento do estoque informado pelo usuário se o mesmo se existir no estoque;
